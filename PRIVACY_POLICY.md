## Information We Collect

### Location Data
We collect GPS location data to provide core functionality including:
- Tracking your movement and routes
- Recording waypoints and tracks
- Generating statistics and elevation profiles

### Usage Data
- App usage patterns
- Feature interactions
- Crash reports (anonymous)
- Performance metrics

### Device Information
- Device type and model
- Operating system version
- GPS hardware capabilities

## How We Use Your Data

### Primary Purposes
1. **Core Functionality**: Enable GPS tracking and route recording
2. **Statistics Generation**: Process location data to create elevation profiles and statistics
3. **Feature Enhancement**: Improve user experience based on usage patterns
4. **Bug Detection**: Use crash reports to improve app stability

### Data Storage
- Location data is stored locally on your device
- No automatic cloud backup or synchronization
- Data remains private unless you explicitly export it
- Export functionality only saves to your chosen location

### Data Sharing
- We do not sell, trade, or share your personal data
- No third-party advertising networks
- No analytics data is shared without explicit consent
- All data processing occurs on your device

## Data Retention

### Location Data
- Retained until manually deleted by user
- Can be exported and backed up at any time
- No automatic deletion or expiration

### Usage Statistics
- Temporary crash reports (if enabled)
- Aggregated, anonymized statistics
- Can be disabled in settings

## Your Rights

### Access
- View all collected data through app export features
- Export your GPS tracks and notes

### Deletion
- Delete all stored data from your device
- Remove all recorded tracks and notes

### Control
- Enable/disable location services

- Choose when to share data (if ever)

## Security

### Data Protection
- Local storage only (no cloud unless user exports)

- **Camera**: Optional, for photo notes
- **Microphone**: Optional, for audio notes
